Десктопное приложение для управления объектами недвижимости и процессами их аренды.

## 📌 О проекте

**Система аренды недвижимости** — информационная система, предназначенная для автоматизации работы с объектами недвижимости, которые передаются в аренду.

Приложение позволяет хранить и обрабатывать информацию об объектах недвижимости, их владельцах и арендаторах, а также вести учет договоров аренды и связанных с ними платежей.

Главное окно приложения предоставляет доступ к основным разделам системы:

* управление недвижимостью;
* управление владельцами;
* управление арендаторами;
* управление договорами;
* управление платежами.

Таким образом, основные операции с данными собраны в одном приложении и доступны через единый пользовательский интерфейс.

---

## ✨ Основные возможности

### 🏢 Управление недвижимостью

Раздел предназначен для работы с объектами недвижимости.

В зависимости от реализации конкретного представления пользователь может:

* просматривать список объектов;
* добавлять новые объекты;
* редактировать существующие данные;
* удалять объекты;
* работать с информацией об объектах, передаваемых в аренду.

### 👤 Управление владельцами

Раздел позволяет вести учет собственников недвижимости.

Основные операции:

* просмотр владельцев;
* добавление владельца;
* редактирование информации;
* удаление записи.

### 🧑‍💼 Управление арендаторами

Предназначен для хранения информации об арендаторах.

В разделе можно выполнять операции с данными арендаторов и использовать их при оформлении договоров аренды.

### 📄 Управление договорами

Раздел предназначен для учета договоров аренды.

Договор связывает информацию об объекте недвижимости и арендаторе и позволяет вести учет условий аренды.

### 💳 Управление платежами

Раздел используется для учета платежей, связанных с договорами аренды.

Это позволяет отслеживать финансовые операции, связанные с арендой недвижимости.

## 🏗 Архитектура проекта

Проект организован по принципу разделения приложения на несколько логических частей.

```text
kursOOP
│
├── Data
│   └── Работа с данными и контекстом БД
│
├── Properties
│   └── Свойства проекта
│
├── Services
│   └── Сервисы приложения
│
├── Utils
│   └── Вспомогательные классы и методы
│
├── ViewModels
│   └── Логика представлений
│
├── Views
│   └── Пользовательские окна и представления
│
├── App.config
├── App.xaml
├── App.xaml.cs
├── Program.cs
├── kursOOP.csproj
└── kursOOP.sln
```

Репозиторий содержит отдельные каталоги `Data`, `Services`, `Utils`, `ViewModels` и `Views`, что позволяет разделять работу с данными, бизнес-логикой и интерфейсом.

---

## 📁 Структура проекта

### `Data`

Содержит компоненты, отвечающие за взаимодействие приложения с данными и базой данных.

### `Services`

Содержит сервисный слой приложения.

Сервисы используются для вынесения операций над данными и бизнес-логики из пользовательского интерфейса.

### `Utils`

Вспомогательные классы и методы, используемые различными частями приложения.

### `ViewModels`

Слой ViewModel содержит логику, необходимую представлениям WPF.

Использование ViewModel позволяет отделить пользовательский интерфейс от основной логики приложения.

### `Views`

Содержит XAML-представления приложения.

Главное окно системы предоставляет пользователю доступ к пяти основным направлениям работы:

```text
Управление недвижимостью
        │
        ├── Управление владельцами
        │
        ├── Управление арендаторами
        │
        ├── Управление договорами
        │
        └── Управление платежами
```

Главное окно реализовано на WPF и содержит соответствующие кнопки навигации.

## 💻 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/whylovely/kursOOP.git
```

Перейдите в каталог проекта:

```bash
cd kursOOP
```

### 2. Открытие проекта

Откройте файл:

```text
kursOOP.sln
```

с помощью **Visual Studio**.

### 3. Восстановление зависимостей

После открытия проекта Visual Studio должна восстановить необходимые NuGet-зависимости.

В проекте используется **Entity Framework 6.5.1** и связанные библиотеки для работы с базой данных.

При необходимости выполните:

```powershell
Update-Package -reinstall
```

в Package Manager Console.

## ▶️ Запуск

После открытия решения:

1. Убедитесь, что проект `kursOOP` установлен как **Startup Project**.
2. Выберите конфигурацию `Debug`.
3. Нажмите:

```text
F5
```

или запустите проект без отладки:

```text
Ctrl + F5
```

Точка входа приложения находится в `Program.cs`, где создается экземпляр WPF-приложения и запускается основной цикл приложения.

## 🗄 База данных

Для работы с базой данных используется **Entity Framework**.

Конфигурация Entity Framework находится в:

```text
App.config
```

В конфигурации проекта указан провайдер:

```text
System.Data.SqlClient
```

а приложение использует SQL Server для работы с данными.

Перед первым запуском необходимо убедиться, что:

* SQL Server установлен и запущен;
* база данных доступна;
* строка подключения настроена в соответствии с локальной конфигурацией;
* у пользователя есть права на подключение к базе данных.

## 🔄 Принцип работы

Типичный сценарий работы пользователя:

```text
Запуск приложения
        ↓
Главное меню
        ↓
Выбор раздела
        ↓
Работа с данными
        ↓

        ↓
Возврат в главное меню
```

Например, для оформления аренды:

```text
Владелец
   ↓
Объект недвижимости
   ↓
Арендатор
   ↓
Договор аренды
   ↓
Платежи
```

Такой подход позволяет связать основные сущности предметной области и организовать единый процесс учета аренды.

## 🔧 Возможные проблемы

### Не восстанавливаются NuGet-пакеты

Попробуйте выполнить восстановление пакетов через Visual Studio:

```text
Tools → NuGet Package Manager → Package Manager Settings
```

или использовать Package Manager Console.

### Ошибка подключения к SQL Server

Проверьте:

1. Запущен ли SQL Server.
2. Правильно ли указано имя сервера.
3. Существует ли необходимая база данных.
4. Имеет ли пользователь права на подключение.
5. Корректно ли указана строка подключения.

### Ошибка версии .NET Framework

Убедитесь, что на компьютере установлен **.NET Framework 4.8**, поскольку проект ориентирован именно на эту версию.
